## [0.5.0] - 2026-11-06

### Changed

- CorridorKey Inference and CorridorKey Video Inference report problems with the parameter named
  and a fix to try, such as "Connect an image to 'Image'." or "'Mask Hint' is required when
  'Hint Source' is 'videomama'." The node name and the "CorridorKey inference failed:" prefix are
  gone from the status text.
  [#15](https://github.com/griptape-ai/griptape-nodes-library-corridorkey/issues/15)
